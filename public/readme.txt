Sri Tirumala - Static Assets Directory
=======================================

You can place your custom logo and product images in this folder (or sub-folders).

Examples:
1. CUSTOM LOGO:
   Place an image named "logo.png" or "logo.jpg" directly in this folder.
   The website is configured to look for "/logo.png" (or similar) and will automatically display it as your header logo, falling back to the 🥥 emoji if not found.

2. PRODUCT IMAGES:
   Place your product images here, for example:
   - "almonds.jpg" -> can be referenced in the dashboard as "/almonds.jpg"
   - "cashews.png" -> can be referenced in the dashboard as "/cashews.png"

You can organize them into a subfolder too, e.g., "public/images/almonds.jpg" and reference it as "/images/almonds.jpg".
